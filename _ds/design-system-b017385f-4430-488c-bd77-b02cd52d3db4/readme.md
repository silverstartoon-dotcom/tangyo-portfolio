# 조은별 · 인스타툰 광고 소재 Design System

퍼포먼스 광고 소재를 기획·제작하는 콘텐츠 디자이너 **조은별**의 B2B 포트폴리오용 디자인 시스템입니다.
브랜드 자산은 소속 네트워크 **만화제면소**(인스타툰 전문 크리에이터 네트워크)에서 제공받았습니다.

## 이 시스템이 해결하는 문제

포지셔닝이 전부입니다. 광고주가 10~20초 안에 "그림 잘 그리는 인스타툰 작가"가 아니라
**"광고 목적에 맞는 인스타툰 콘텐츠를 기획하고 제작할 수 있는 광고 소재 제작자"**로 인식해야 합니다.
따라서 이 시스템의 모든 컴포넌트는 작업물을 크게 보여주고, 그 옆에 항상
OBJECTIVE / APPROACH / (있을 때만) RESULT를 붙입니다. 그림 단독 갤러리는 이 시스템에 존재하지 않습니다.

계정 중심이 아닌 **소재 제작 중심** 시스템입니다. 팔로워 수, 계정명, 조회수를 전면에 두는 컴포넌트는
의도적으로 만들지 않았습니다.

## 제공받은 소스

- **캐릭터**: 12종 전신 라인아트 PNG (1024×1024, 흰 배경) — 김대리, 김사원, 김사장, 김상무, 뀨, 명화씨, 박대리, 백슈, 연민수과장, 왕팀장, 유해진과장, 한입만과장
- **성과소개서_만화제면소.pdf** (19p, 이미지 전용 PDF) → `assets/docs/manjeso-performance-deck.pdf`
  컬러·타이포·레이아웃 어휘를 여기서 추출했습니다. 페이지 렌더는 `scraps/pdf-*.png`.
- **채널 데모그래픽**: 25–44세 70% / 남 50 : 여 50
- **연락처**: silverstar.toon@gamil.com · 만화제면소 문의 https://salestracker-eight.vercel.app/c/c-ayz7rebu0r8prq · 홈페이지 https://manjeso.com/

### 아직 받지 못한 것

- **실제 작업물 이미지 파일** — '조은별 포트폴리오' 프로젝트 폴더에 접근할 수 없습니다. 모든 캐러셀은 현재 `[CREATIVE NN]` placeholder입니다.
- **성과 데이터** — 조은별 본인 기준 수치는 제공되지 않았습니다. 유일한 수치(시그널플래너 링크 클릭 유입 1.6만+)는 만화제면소 성과소개서에서 인용한 것으로, 귀속 확인이 필요합니다.
- **헤드라인 폰트 파일** — 아래 타이포그래피 항목 참조.

## CONTENT FUNDAMENTALS

**국문 본문 · 라틴 라벨.** 이것이 이 브랜드 카피의 핵심 규칙입니다.
섹션 이름, CTA, 필드 이름은 전부 라틴 대문자에 자간을 넓게 벌립니다 — `WORK`, `CONTACT`,
`SELECTED WORK`, `OBJECTIVE`, `PROJECT INQUIRY`. 설명과 주장은 전부 국문입니다.
국문 CTA 버튼은 만들지 않습니다(다운로드 버튼처럼 기능이 국문일 때만 예외).

**말하는 사람은 '저'입니다.** 1인칭 겸양체(–습니다/–합니다)로 일관합니다. '작가님', '우리 팀' 같은
호칭은 쓰지 않습니다. 광고주는 '브랜드', '광고주'로 지칭합니다.

**주장은 짧은 단정문, 근거는 한 문단.** 덱에서 가져온 리듬입니다.

> 넘기는 광고가 아니라, **끝까지 읽히는 광고** (만화제면소 덱 표지)
> 광고 같지 않게, 광고 메시지를 전달합니다.
> 광고는 보여주는 것보다 멈춰서 보게 만드는 것이 중요하니까.

헤드라인은 두 줄로 끊고 강조어를 오렌지로 색만 바꿉니다. 밑줄·형광펜·굵기 변화는 쓰지 않습니다.

**수치 표기.** 제공된 수치만 큰 글씨로 씁니다. 반드시 기준을 한 줄로 붙입니다
("본 성과는 캠페인 성과이며, 스폰서드 광고 활용비까지 포함한 기준입니다."). 수치가 없으면
`[RESULT]`, `[BRAND]`, `[OBJECTIVE]` 형태의 placeholder를 그대로 둡니다 — 추정치로 채우지 않습니다.

**이모지는 쓰지 않습니다.** 유니코드 글리프는 화살표(`→` `↗` `↓`)와 가운뎃점(`·`), 캐러셀 화살표(`‹` `›`)만 허용합니다.
덱에는 네 갈래 반짝임(`✧`) 장식이 있으나 웹에서는 절제해서 씁니다.

**어투 체크리스트** — 광고주가 읽고 다음 질문에 답할 수 있어야 합니다: 무엇을 만들어주는가 /
어떤 형태인가 / 어떻게 기획하는가 / 어떻게 맡기는가. 철학·감상·포부는 쓰지 않습니다.

## VISUAL FOUNDATIONS

**컬러.** 브랜드는 실질적으로 3색입니다: 오렌지 `#ff4e17`, 잉크 `#101010`, 흰색.
오렌지는 로고 파일에서 직접 추출한 값입니다. 나머지는 따뜻한 회색 11단(`--n-0`…`--n-950`)이며
파랑·보라·녹색 계열 액센트는 시스템에 없습니다. 오렌지는 **한 화면에 한 역할** — 강조어, 라벨,
주 CTA, 또는 하나의 풀블리드 밴드 중 하나만. 둘 이상에 동시에 쓰면 작업물보다 UI가 먼저 보입니다.

**배경.** 페이지는 `--n-950` 다크가 기본입니다(크리에이티브 스튜디오 톤). 리듬은 세 가지 지면을
번갈아 쓰는 것으로 만듭니다: 다크(`#0a0a0a`) → 오렌지 풀블리드 → 잉크(`#101010`).
그라디언트는 쓰지 않습니다. 텍스처·패턴·노이즈도 없습니다. 유일한 장식 도형은 **기울인 밴드**입니다.

**기울인 밴드(시그니처).** 덱의 사선 컷에서 가져왔습니다. 섹션을 `--skew-band: -2.6deg`로 기울이고
내부 콘텐츠를 `+2.6deg`로 되돌립니다. 페이지당 한 번, 포지셔닝 문장에만 씁니다.

**타이포그래피.** Pretendard 한 종으로 전부 처리합니다. 헤드라인 900, 본문 400–500, 라벨 700.
국문 헤드라인은 자간을 좁게(`-.035em`), 라틴 라벨은 넓게(`.16em`–`.26em`) — 이 대비가 브랜드의
타이포 지문입니다. 국문은 `word-break: keep-all` 필수(단어 중간에서 끊기면 즉시 아마추어로 보입니다).

> **폰트 대체 안내:** 만화제면소 덱 헤드라인은 더 굵고 약간 좁은 국문 고딕(플랫한 종단 처리)이며
> 폰트 파일을 제공받지 못했습니다. 현재 Pretendard Black(900)으로 대체했습니다. 원본 폰트 파일이
> 있으면 보내주세요 — `tokens/fonts.css` 한 파일만 교체하면 전체에 반영됩니다.

**작업물 이미지 처리.** 작업물은 있는 그대로, 최대한 크게, 자르지 않고 보여줍니다. 필터를 걸지
않습니다. 예외는 덱의 **듀오톤 블록** 어휘로, 인용·썸네일 맥락에서만 `--toon-duotone`
(grayscale + contrast 1.06)을 오렌지 또는 검정 사각 블록 위에 얹어 씁니다. 본편 캐러셀에는 걸지 않습니다.

**캐릭터 사용.** 선화는 검정 잉크입니다. 따라서 타일 바탕은 **항상 흰색 또는 오렌지** — 다크 배경에
직접 얹으면 선이 사라집니다. `assets/characters/cutout/`(흰 배경 제거본)을 씁니다. 한 줄에서 흰색과
오렌지 바탕을 번갈아 배치하고, 호버 시 `-1.2deg` 회전 + 4px 상승으로 스티커 느낌을 줍니다.

**모서리.** 거의 직각입니다: 버튼·태그 2px, 카드·이미지 4px, 그 이상은 쓰지 않습니다(`--r-pill`은
캐러셀 점과 카운터에만). 브랜드 감각은 잉크와 인쇄 블록이므로 부드러운 UI 라운딩은 피합니다.

**카드.** 다크 배경에 `--n-900` 면, 1px 헤어라인 테두리, **상단 3px 라인**이 특징입니다. 호버 시
상단 라인이 오렌지로 바뀌고 카드가 3px 올라갑니다. 흰색 'paper' 카드는 한 줄에 최대 하나만 —
강조용 반전입니다.

**보더와 구분선.** 섹션 구분은 `rgba(255,255,255,.1)` 1px 한 줄. 요소 강조는 2px
(`--line-strong`). 3px 블록 라인은 카드 상단 전용입니다.

**그림자.** 다크 지면에서 깊이는 명도로 만듭니다. `--shadow-card`는 거의 보이지 않는 수준이고,
`--shadow-sticker`(6px 오프셋, 블러 0)는 흰색/오렌지 카드에만 씁니다. 부드러운 드롭섀도는 없습니다.

**투명도와 블러.** 두 곳만 씁니다 — 스티키 헤더(`rgba(10,10,10,.82)` + `blur(14px)`)와 캐러셀
오버레이 컨트롤. 그 외에는 불투명한 면을 씁니다. 본문 텍스트에 알파를 쓰지 않습니다(대비 유지).

**모션.** 짧고 평평합니다. 120ms 호버, 200ms 상태 전환, 420ms 진입 페이드.
`--ease-out: cubic-bezier(.2,.7,.25,1)`. 바운스·스프링·패럴랙스·스크롤 하이재킹은 쓰지 않습니다.
이동 거리는 최대 14px. 진입 애니메이션은 HERO 한 번만.

**호버/프레스.** 호버 = 테두리가 오렌지로, 또는 오렌지 배경이 `--mj-orange-700`으로 어두워짐.
프레스 = `translateY(1px)`. 투명도 변화로 상태를 표현하지 않습니다.

**레이아웃.** 모바일 우선입니다(광고주에게 링크로 전달되므로). 거터 `clamp(20px, 5vw, 72px)`,
콘텐츠 최대 1280px. 섹션 사이 `clamp(72px, 11vw, 168px)`. 고정 요소는 스티키 헤더 하나뿐입니다.
작업물은 모바일에서 거터 폭을 꽉 채우고, 320px 미만으로 축소하지 않습니다.

## ICONOGRAPHY

아이콘 세트가 없습니다 — 제공된 소스(로고 PNG, 캐릭터 라인아트, 이미지 PDF)에 아이콘 시스템이
존재하지 않고, **의도적으로 만들지 않았습니다.** 이 브랜드는 아이콘 대신 **라틴 라벨**로 의미를 전달합니다.

허용하는 글리프는 전부 유니코드 텍스트입니다:

| 글리프 | 용도 |
| --- | --- |
| `→` | 주 CTA 후행 화살표 |
| `↗` | 외부 링크 (만화제면소 홈페이지, 문의 링크) |
| `↓` | 다운로드 |
| `‹` `›` | 캐러셀 이전/다음 |
| `·` | 라벨 구분자 |
| `✧` | 덱 장식(웹에서는 최소 사용) |

이모지는 쓰지 않습니다. SVG 아이콘을 새로 그리지 않습니다. 아이콘이 꼭 필요한 화면이 생기면
Lucide(1.5px 스트로크, 라운드 캡)를 CDN으로 얹는 것을 권장하되, **그 선택은 대체이며 브랜드
자산이 아님**을 명시하세요. 로고와 심볼은 제공된 PNG 파일만 사용하고 재조판하지 않습니다.

## COMPONENTS

`components/` — 컴파일되어 `window.<Namespace>`로 노출됩니다. 각 디렉터리에 `@dsCard` 카드가 있습니다.

**core/**
- `Button` — 직각 라틴 대문자 CTA. primary / inverse / outline / ghost, sm / md / lg
- `Tag` — 카테고리 칩 (뷰티, 보험, F&B…)
- `SectionLabel` — 섹션 아이브로우. 01형 인덱스 + 헤어라인
- `StatFigure` — 초대형 성과 수치. 실제 제공 수치에만 사용

**work/**
- `ToonCarousel` — 인스타그램형 컷 스와이프 뷰어. 4:5 기본, 9:16 옵션
- `WorkCase` — 캐러셀 + BRAND / CATEGORY / OBJECTIVE / APPROACH / RESULT

**pitch/**
- `OfferCard` — 의뢰 가능한 포맷·형태 타일
- `ProcessStep` — 5단계 제작 프로세스 한 줄
- `CharacterCard` — 캐스팅 가능한 캐릭터 스티커 타일
- `CopyField` — 클릭 복사 연락처 필드 (이메일)

### Intentional additions

원본 소스에 컴포넌트 라이브러리가 없어(브랜드 자산과 덱만 제공) 위 10종은 이 포트폴리오가
실제로 필요한 범위에 맞춰 새로 만든 것입니다. 일반적인 디자인 시스템에 흔한 Input, Select,
Dialog, Toast, Tabs 등은 이 사이트에 쓰이지 않으므로 만들지 않았습니다.
